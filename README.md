# Telegram Cleanup Bot

1. Создай бота через @BotFather.
2. Добавь бота в группу как администратора с правом «Удаление сообщений».
3. Задай BOT_TOKEN в переменных окружения хостинга и запусти `python bot.py`. Нужен Python 3.10+.
4. Ответь на любое сообщение нужного участника одной из команд:
   - `/purge 5000` — до 5000 его последних доступных сообщений.
   - `/purge 6ч` — все доступные сообщения автора за последние 6 часов.
   - `/purge 30м` — за 30 минут. Поддерживаются также ч/д и h/m/d.
5. Проверь автора и число найденных сообщений. Нажми «Удалить» в течение двух минут. Подтверждение доступно только администратору, отправившему команду.

Поиск идёт по всей группе, включая другие темы. Выбранный автор определяется по ID. Бот индексирует сообщения, которые Telegram присылает после подключения, и может также учесть отдельное сообщение, на которое ты ответил командой. Bot API позволяет удалять сообщения моложе 48 часов. Анонимные сообщения от имени группы или канала не используются для выбора автора.

Запускай один экземпляр бота. Если хостинг поддерживает постоянный диск, укажи в DB_PATH путь к файлу на нём, например /data/messages.sqlite3. База хранит только ID и даты сообщений. Записи старше 48 часов автоматически очищаются. В архиве нет токена.
